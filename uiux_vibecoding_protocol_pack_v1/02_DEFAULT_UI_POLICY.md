# 02_DEFAULT_UI_POLICY: 既定UI思想

## 1. 基本思想
本資料群の既定UIは、PC優先の業務・管理・制作支援・編集ツール向けである。ランディングページや販促SaaS風の余白過多デザインではなく、日常的に何度も使う作業画面を前提にする。初見の分かりやすさは必要だが、常用効率・情報密度・視線移動の少なさを優先する。

## 2. 優先順位
1. 作業目的の達成速度。
2. 情報階層の明確さ。
3. 一覧性・比較性・編集しやすさ。
4. 誤操作防止と回復可能性。
5. アクセシビリティ。
6. 初見理解。
7. 見た目の親しみやすさ。
8. 装飾的な美しさ。

## 3. 基本禁止事項
- Primary buttonを複数並べない。
- 補助操作を巨大ボタンにしない。
- 「展開する」「閉じる」「詳細を表示する」などの長文ボタンを常時表示しない。
- 比較・一覧・編集画面を安易にカードグリッド化しない。
- placeholderをlabel代わりにしない。
- 低頻度操作を常時露出しない。
- 破壊的操作を通常操作の隣に置かない。
- 画面中央に意味なく操作ボタンを散らさない。
- 余白を「おしゃれ」のためだけに増やさない。
- 実装前モックなしで複雑UIを作らない。

## 4. 基本レイアウト
|領域|役割|
|---|---|
|Header / Toolbar|画面タイトル、状態、検索、主要操作、表示切替|
|Left Sidebar|ナビゲーション、カテゴリ、プロジェクト/ファイル選択|
|Main Content|表、リスト、編集対象、主作業領域|
|Right Panel / Inspector|詳細、プロパティ、補助設定、選択項目の編集|
|Row End|行単位の編集、複製、削除、詳細|
|Overflow Menu|低頻度、上級、補助、危険ではないが常時不要な操作|
|Danger Zone|削除、初期化、一括上書き等|

## 5. 文言方針
- 常時表示は短語。保存、追加、編集、複製、出力、取込、削除、設定など。
- 説明はtooltip, helper text, empty state, aria-labelへ分離する。
- 主要操作は短い日本語ラベルを優先する。
- icon-onlyは高頻度・既知・補助操作だけ。
- 日本語UIでは語尾「する」を原則落とす。例: 保存する→保存、追加する→追加。

## 6. 既定密度
- density: compact。
- control height: 28〜32pxを基本、主要操作のみ40pxまで許容。
- table row height: 28〜36px。
- toolbar height: 36〜44px。
- spacing: 4px/8px/12px/16px/24pxを基本単位にする。

## 7. 既定アクセシビリティ
- focus visibleを消さない。
- icon-onlyにはtooltipとaria-labelを付ける。
- form inputにはvisible labelを付ける。
- contrastはWCAG 2.2 AA相当を目標にする。
- target sizeは最低24px、タッチ主体なら44px程度を検討する。
- status messageは視覚表示だけでなく支援技術にも伝わるようにする。
